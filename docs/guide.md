# 学习指南与统一符号

## 先建立三条主线

第一条是**概率主线**：先验、似然、后验 → 参数估计 → 回归中的噪声假设 → 概率图模型。第二章建立的贝叶斯公式会贯穿全书。

第二条是**几何与优化主线**：向量、内积和超平面 → 感知机、Fisher 判别和 logistic → 最大间隔与核方法 → 神经网络的反向传播。学习时要能同时说清“图上做什么”和“目标函数是什么”。

第三条是**表示主线**：原始数据变成特征 → 相似性与聚类 → 特征选择、PCA → 网络自动学习表示。特征不是问题的透明容器；单位、缩放、编码方式都会影响算法。

保留课件的十章结构。首次学习按目录顺序；第三章的模型评价先学，会帮助后续所有实验。第八章的熵也可在第四章决策树之前预读。第九章需要第二章与第八章，第十章的 BP 需要第三章的梯度下降。

## 前置知识如何自检

应当会求条件概率、期望和方差，会做向量内积、矩阵乘法、特征分解，并理解导数与链式法则。遇到矩阵逆时先问矩阵是否可逆；遇到概率乘积时先问独立性来自哪里。缺少这些基础时，先完成相关章节的二维或一维例子，再读一般形式。

## 统一符号

| 符号 | 对象与含义 | 维度或范围 |
| --- | --- | --- |
| $N$ | 训练样本数，已知整数 | $N\ge1$ |
| $d$ | 原始特征维度 | 正整数 |
| $K$ | 类别数或簇数，须由语境区分 | 正整数 |
| $\mathbf x_i$ | 第 $i$ 个已观测特征，列向量 | $\mathbb R^d$ |
| $y_i$ | 第 $i$ 个标签或回归响应 | 分类标签／实数 |
| $D$ | 训练数据集合 | $\{(\mathbf x_i,y_i)\}_{i=1}^N$ |
| $\mathbf w,b$ | 待学习的权重和偏置 | $\mathbb R^d,\mathbb R$ |
| $X$ | 按行放样本的设计矩阵 | $N\times d$ |
| $\boldsymbol\mu,\Sigma$ | 随机向量的均值、协方差 | $d,\ d\times d$ |
| $S_W,S_B$ | 类内、类间散度矩阵 | $d\times d$ |
| $\theta$ | 一般待估参数；硬币例中为成功概率 | 由模型确定 |
| $P(A)$ | 事件或离散结果概率 | $[0,1]$ |
| $p(x)$ | 连续密度或一般概率模型 | 密度可大于 1 |
| $\eta$ | 学习率 | $\eta>0$ |
| $\lambda$ | 正则强度或特征值 | 局部重新说明 |

本书 $X$ 按行放样本；部分课件按列放样本，出现转置差异时应检查维度，不能直接照搬公式。$\log$ 默认自然对数；以 2 为底的熵写作 $\log_2$，单位 bit。

公式在 Markdown 中用 `$...$` 和 `$$...$$`。提示词建议的行间 `\(...\)` 通常是行内定界符，因此本项目采用能稳定渲染的标准行间形式。构建时使用本地 KaTeX，断网后仍可阅读数学公式。

## 一章的使用方法

先读问题与例子，再亲手写一次推导。完成练习时先遮住解答，说明假设、定义符号、写出目标、再计算。最后回到来源页段，分清课件已经讲过的内容与编者补充。

每次实验都记录训练／验证／测试的角色。测试集用于最后一次评估；标准化、PCA、特征选择与超参数选择必须只从训练流程中学习。随机数据须固定种子。本项目手算实验采用确定性小数据，不依赖一次随机运行来论证结论。
