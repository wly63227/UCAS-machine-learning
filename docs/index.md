# 机器学习：从数据到决策

这套笔记围绕一个问题展开：怎样从有限数据中得到能用于新样本的模型？概率论描述不确定性，几何描述样本关系，优化把学习目标变成可计算的算法。

本版以 **2026 年已提供的前三章课件**为主，第四至第十章依据文件夹内的往年课件编写。后续章节可用于提前学习，不能据此判断本年度授课或考试范围。当前是可阅读的教材初稿，尚未完成全课件逐页视觉验收；具体边界见[验收记录](audit.md)。
